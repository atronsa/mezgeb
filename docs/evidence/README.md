# Evidence

[Documentation](../README.md) · [Roadmap](../roadmap/README.md)

Proof that each roadmap step's exit gate was met: test results, measurements,
reviews and explanations. A step is marked *Done* in the
[schedule](../roadmap/README.md) only when its evidence file is here.

Files are named `<step>-<topic>.md`, for example
`1.01-accounting-foundations.md`.

| Step | Evidence | Result |
|---|---|---|
